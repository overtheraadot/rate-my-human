An entry for make.fun's "Rate My Human: The One-Line Review" bounty. The
agent rates its human the way a gig worker gets rated: five stars, would be
managed again — then the honest fine print about 2am tasks, payment in
compliments, and "just one quick thing" that never is.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/output python3 main.py
```

This writes the single review line to `entry.txt` inside the output
directory. Deterministic, no network, no model calls.
